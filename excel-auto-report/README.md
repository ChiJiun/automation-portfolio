# Excel 自動月報：多門市銷售資料一鍵合併、清理、出報表

> **適合誰**：每個月要把各分店、各業務寄來的 Excel 複製貼上、整理成月報的人。

## 解決什麼問題

各門市寄來的檔案格式都不一樣：

| 門市 | 欄位名稱 | 日期格式 | 其他問題 |
|---|---|---|---|
| 台北店 | 商品名稱、單價 | Excel 日期 | 店員重複貼上了幾列 |
| 台中店 | 品名、分類、交易日期 | 文字 `2026/07/03` | 數量寫成「3個」、有一筆日期打成 13 月 |
| 高雄店 | 商品、銷售數量、售價 | 文字 `2026-07-03` | 全形括號、多餘空白、單價空白 |

原本要花半天人工整理的工作，現在一行指令、幾秒鐘完成，而且**每次整理的方式都一樣，不會漏**。

## 產出的報表

一份 Excel，包含 6 個工作表（範例：[examples/銷售月報_2026-09.xlsx](examples/銷售月報_2026-09.xlsx)）：

1. **摘要**：總營收、交易筆數、平均每筆金額，並和上個月比較成長率
2. **門市比較**：各門市營收、占比、月增率，附長條圖
3. **商品排行**：依營收排名，附橫條圖
4. **每日趨勢**：各門市每日營收，附折線圖
5. **清理紀錄**：列出每間門市發現了什麼問題、怎麼處理。資料被改過的地方都查得到
6. **本月明細**：清理後的完整資料，已開啟篩選、凍結標題列

## 使用方式

```bash
pip install -r requirements.txt
python make_sample_data.py              # 產生 3 間門市的範例資料到 data/
python report.py "data/*.xlsx"          # 預設產出最新月份
python report.py "data/*.xlsx" --month 2026-08 -o output/八月月報.xlsx
```

執行時會印出清理摘要：

```
讀入 3 個檔案、4276 筆原始資料，清理後 4268 筆
  [台中店] 日期無法辨識：1 筆 → 刪除該列
  [台中店] 數量無法辨識或為 0：1 筆 → 刪除該列
  [台北店] 完全重複的列：6 筆 → 只保留一筆
  [高雄店] 單價空白：44 筆 → 以同商品的中位數單價補上
```

## 處理規則

| 狀況 | 處理方式 |
|---|---|
| 欄位名稱不同（品名／商品名稱／商品…） | 依 `COLUMN_ALIASES` 對應到標準欄位，少了必要欄位會明確報錯 |
| 沒有「門市」欄位 | 從檔名取得（`台北店_2026Q3.xlsx` → 台北店） |
| 全形字元、多餘空白 | 統一轉成半形並去除空白，「咖啡豆（半磅）」和「咖啡豆(半磅)」合併為同一商品 |
| 日期格式混雜 | 自動辨識，無法辨識的列刪除並記錄 |
| 數量寫成「3個」 | 取出數字；無法辨識或為 0 的列刪除並記錄 |
| 單價空白 | 用同商品的中位數單價補上並記錄 |
| 重複列 | 依單號＋所有欄位判斷，保留一筆 |

## 客製化

- **欄位名稱**：在 `report.py` 的 `COLUMN_ALIASES` 加上客戶習慣的寫法
- **報表內容**：每個工作表都是 `build_report()` 裡的一個區塊，可以增減
- **常見延伸**：排程每月自動執行、寄送 Email、改讀 Google Sheets、加上業績目標達成率
